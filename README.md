# itg-rag

Основа проекта RAG. Функциональность будет добавлена по ТЗ.

Проект использует Python 3.13+, `uv` и структуру пакета `src/itg_rag`.
Прикладные зависимости пока отсутствуют. В группе `dev` установлены
`pytest`, `ruff` и `ty` для тестирования, форматирования и проверки типов.

## Установка

Установите `uv`, затем выполните в корне проекта:

```sh
uv sync --locked
```

Команда создаст `.venv` и установит пакет вместе с инструментами разработки.
Версия Python для локальной разработки закреплена в `.python-version`:
`3.13`. При необходимости `uv` скачает интерпретатор автоматически.
Для установки только пакета без инструментов разработки:

```sh
uv sync --locked --no-dev
```

## Команды разработки

| Команда | Действие |
| --- | --- |
| `make install` | Установить окружение из `uv.lock` |
| `make test` | Запустить pytest |
| `make lint` | Проверить код с Ruff |
| `make format` | Отформатировать код |
| `make fix` | Исправить замечания Ruff и отформатировать код |
| `make typecheck` | Проверить типы с ty |
| `make check` | Запустить линтер, проверку формата, типов и тесты |

`make check` использует `scripts/check.sh`: показывает результат каждого
этапа, выполняет все проверки и возвращает ненулевой код при ошибке.
Настройки Ruff и pytest перенесены из `itg-llm` и адаптированы к `itg_rag`.
Текущий smoke-тест проверяет импорт пакета и доступность метаданных установки.

## Добавление зависимостей

```sh
uv add <package>
uv add --dev <tool>
```

Сохраняйте изменения `pyproject.toml` и `uv.lock` вместе.
`.venv`, кэши, результаты сборки и `.env` исключены из Git.
